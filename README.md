# IAP Gesprächsführung – Kitteltaschen-App

Kitteltaschen-Begleiter für ärztliche Gesprächsführung  
Universität Witten/Herdecke · Institut für Ausbildung personaler und interpersonaler Kompetenzen

## Entwicklung lokal starten
```bash
npm install
npm run dev
```

## Deployment
Automatisch via GitHub Actions bei jedem Push auf `main`.
